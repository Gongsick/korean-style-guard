# AI 문체 감별·교정 기준

**v2.0 / 2026-09-01**
원본(어휘·관용구 목록)에 문법·리듬·문체 정합 층위를 더해 재구성했다.

---

## 0. 이 문서를 쓰는 법

AI 문체 문제는 하나의 층위에서 생기지 않는다. 다섯 층위가 있고, **아래로 갈수록 고치기 어렵고 티는 더 크게 난다.**

| 층위 | 대상 | 원본 커버 | 교정 난이도 | 티 나는 정도 |
|---|---|---|---|---|
| L1 어휘 | 상투 관용구, 과장 수식어 | ○ | 낮음 | 중 |
| L2 문법 | 피동·명사화·조사 번역투 | △ | 중 | 중 |
| L3 문장 | 길이·어미·병렬 리듬 | ✕ | 중 | 높음 |
| L4 구성 | 문단 골격, 서식 과잉 | ✕ | 높음 | 높음 |
| L5 문체 정합 | 지정 문체와 나머지 4층의 불일치 | ✕ | 높음 | **가장 높음** |

**"문체를 지정했는데 어색하다"는 증상은 거의 전부 L5다.** 어미만 바꾸고 L1~L4는 문어체 그대로 두면, 옷만 갈아입은 보고서가 나온다. L1 금지어 목록만 들고 교정하면 이 문제는 절대 안 잡힌다.

## 1. 왜 이런 문체가 나오는가

목록을 외우는 것보다 원인을 아는 쪽이 낫다. 목록에 없는 새 패턴도 같은 원인에서 나오기 때문이다.

**① 최빈값 회귀**
다음 토큰으로 가장 무난한 것을 고르는 구조라, 문장이 통계적 평균으로 수렴한다. 특정 표현이 틀려서가 아니라 **너무 자주** 나와서 티가 난다. → L1, L3

**② 영어 통사로 생각하고 한국어로 출력**
학습 데이터의 논증적 산문 대부분이 영어다. 어휘는 한국어인데 문장의 뼈대가 영어다. 무생물 주어, 이중 피동, 관계절 중첩이 여기서 나온다. → L2

**③ 안전 편향**
단정을 피하도록 조정되어 있어서, 판단이 필요한 자리마다 hedging·양비론·긍정 전망이 자동으로 채워진다. → L1, L4

**④ 형식 과잉 보상**
구조화된 답이 좋은 답으로 학습됐다. 그래서 세 줄짜리 답에도 소제목·볼드·3항 병렬이 붙는다. → L4

**⑤ 문체 지시의 표층 적용**
"음슴체로" 같은 지시를 **종결어미 치환 명령으로만** 처리한다. 어휘 층위·문장 길이·정보 밀도·화자 거리는 손대지 않는다. → L5, 그리고 이 문서가 원본에 가장 크게 더하는 부분

## 2. L1 — 어휘 층위

### 2-1. 공간·기하 은유의 사물화

추상적 판단을 좌표·물리 구조로 치환하는 습관. 한국어 AI 문체의 가장 뚜렷한 지문이다.

| 상투 표현 | 대체 |
|---|---|
| 축을 세우다 / 축을 형성하다 | 기준을 정하다, 중심에 두다 |
| 기준을 가르다 | 기준을 나누다, 선을 긋다 |
| 궤를 같이하다 / 궤를 달리하다 | 흐름이 같다, 방향이 다르다 |
| 결을 맞추다 / 결이 통하다 | 톤을 맞추다, 방식이 비슷하다 |
| 무게추를 옮기다 | 비중을 옮기다, 더 신경 쓰다 |
| 방점을 찍다 / 방점을 두다 | 강조하다, 중점을 두다 |
| 외연을 확장하다 / 지평을 넓히다 | 범위를 넓히다, 대상을 늘리다 |
| 지형을 바꾸다 / 판을 새로 짜다 | 구도가 바뀌다, 구조를 바꾸다 |
| 스펙트럼이 넓다 | 폭이 넓다, 종류가 다양하다 |
| 접점을 찾다 / 교집합을 만들다 | 겹치는 부분을 찾다, 합의점을 찾다 |
| 층위를 나누다 | 단계를 나누다 (※ 층위는 언어학·구조 분석 문맥에선 정상어) |
| 좌표를 찍다 / 포지셔닝하다 | 위치를 정하다 |
| 결이 다르다 | 성격이 다르다, 종류가 다르다 |
| 톤앤매너를 잡다 | 말투를 정하다, 분위기를 맞추다 |

### 2-2. 영어 관용구 직역

| 상투 표현 | 원문 | 대체 |
|---|---|---|
| 단순히 A가 아니라 B이다 | Not merely A, but B | A이면서 B다 / B이기도 하다 |
| 간극을 좁히다·메우다 | Bridge the gap | 차이를 줄이다 |
| 심층적으로 파고들다 / 깊이 파고들다 | Delve into, Dive deep | 자세히 보다, 뜯어보다 |
| 양날의 검으로 작용하다 | Double-edged sword | 장단점이 같이 있다 |
| 시간의 시험을 견뎌내다 | Stand the test of time | 오래 살아남다 |
| ~의 태피스트리를 엮어내다 | Tapestry of | 얽혀 있다 |
| 게임 체인저 | Game changer | 판도를 바꿀 것 (남용 주의) |
| 빙산의 일각에 불과하다 | Tip of the iceberg | 일부일 뿐이다 |
| ~에 있어 중추적 역할을 하다 | Play a pivotal role | ~에서 핵심이다 |
| 두 마리 토끼를 잡다 | 한국어 관용구지만 AI 사용 빈도가 비정상적으로 높다 | 둘 다 얻다 |
| 청사진을 제시하다 | Blueprint | 계획을 내놓다 |
| 촉매제로 작용하다 | Act as a catalyst | 계기가 되다 |
| 균형점을 찾다 | Strike a balance | 절충하다, 적정선을 찾다 |
| 새로운 장을 열다 | Open a new chapter | 시작되다 |

### 2-3. 수식어 인플레이션

근거 없이 자동으로 붙는 평가어. **삭제해도 뜻이 안 변하면 삭제 대상이다.**

- 형용사: 다양한, 혁신적인, 획기적인, 강력한, 놀라운, 탄탄한, 유의미한, 압도적인, 촘촘한
- 부사: 효과적으로, 성공적으로, 매우, 진정으로, 궁극적으로, 근본적으로, 유기적으로, 전략적으로
- 명사: 핵심, 필수, 본질, 통찰, 인사이트, 시너지, 임팩트

**판별법**: 그 단어를 지우고 읽었을 때 정보가 줄어드는지 본다. 안 줄면 장식이다.

### 2-4. 결말 상투구

결론에서 판단을 내리지 않고 의미만 부여하는 어휘군.

| 상투 표현 | 문제 | 대체 |
|---|---|---|
| 시사하는 바가 크다 / 적지 않다 | 무엇을 시사하는지 안 씀 | 구체적 함의를 직접 쓴다 |
| 단초를 제공하다 / 마중물이 되다 | 계기의 과장 격상 | 계기가 되다, 시작점이 되다 |
| 다각도로 조명해 볼 필요가 있다 | 결론 회피 | 결론을 쓰거나, 무엇이 더 필요한지 특정한다 |
| ~의 역할을 톡톡히 해내다 | 근거 없는 긍정 마무리 | 무슨 역할을 어떻게 했는지 쓴다 |
| 귀추가 주목된다 | 판단 유보 | 뺀다 |
| 향후 지속적인 관심이 요구된다 | 공허한 당위 | 뺀다 |
| ~할 수 있는 대목이다 | 분석 없는 지시 | 뺀다 |
| 곱씹어 볼 만하다 | 감상 대체 | 뺀다 |
| 방향성을 제시한다 | 방향이 뭔지 안 씀 | 방향을 특정해서 쓴다 |

## 3. L2 — 한국어 문법 번역투

### 3-1. 피동 남용

| 유형 | 예 | 교정 |
|---|---|---|
| 이중 피동 | 되어진다, 보여진다, 불려진다, 쓰여진다, 잊혀진다 | 된다, 보인다, 불린다, 쓰인다, 잊힌다 |
| 불필요한 피동 | 논의가 진행되었다 | 논의했다 |
| ~에 의해 | A에 의해 결정된다 | A가 정한다 |
| ~되어야 한다 | 개선되어야 한다 | 개선해야 한다 / 누가 개선하는지 밝힌다 |

행위자를 숨기려는 자리가 아니면 능동으로 쓴다. 책임 소재가 흐려지는 문서(보고서·기안)에서 특히 손해다.

### 3-2. 조사·연결 번역투

| 상투 | 원문 | 교정 |
|---|---|---|
| ~를 통해 | through / via | ~로, ~으로써, ~해서 |
| ~에 대한 / ~에 대해 | about / regarding | ~의, ~를, 아예 생략 |
| ~에 있어서 | in terms of | ~에서, ~할 때 |
| ~와 관련하여 | in relation to | ~에서, ~는 |
| ~로 인해 | due to | ~ 때문에, ~라서 |
| ~을 바탕으로 | based on | ~를 근거로, ~를 보고 |
| ~의 경우 | in the case of | 주어로 바꾼다 |
| ~에 다름 아니다 | 일본어 번역투 | 바로 ~다 |

> "데이터 분석을 통해 문제를 파악할 수 있었다" → "데이터를 보니 문제가 보였다"

### 3-3. 명사화·접미사 연쇄

**"-적/-성/-화/-를 통한/-의" 사슬**은 한국어 서술어를 죽인다.

> ❌ 효율성 제고 및 체계 구축을 통한 확장성 확보
> ✅ 체계를 잡아 효율을 높이고, 나중에 늘리기 쉽게 만든다

- `-적` 연쇄: 구조적, 체계적, 전략적, 유기적, 근본적, 총체적 — 한 문단에 3개 이상이면 과잉
- `-성` 연쇄: 확장성, 지속가능성, 효율성, 안정성
- `-화` 연쇄: 고도화, 체계화, 최적화, 활성화, 내재화
- 명사 3개 이상 연속(`효율성 제고 방안 수립`)은 동사로 푼다

### 3-4. 무생물 주어

영어 통사를 그대로 들여온 형태. 한국어에서는 사람이 주어인 쪽이 자연스럽다.

> ❌ 이번 조사는 세 가지 사실을 보여준다
> ✅ 조사해 보니 세 가지가 나왔다

> ❌ 해당 정책은 사용자 만족도 향상에 기여했다
> ✅ 정책을 바꾸고 나서 만족도가 올랐다

### 3-5. 형식명사 의존

- `~것이다` 종결: 한 문단에 2회 이상이면 리듬이 죽는다
- `~하는 것` 명사절: "확인하는 것이 필요하다" → "확인해야 한다"
- `~라는 점에서`, `~라는 측면에서`: 대부분 삭제 가능
- `~할 필요가 있다`: 대부분 "~해야 한다"로 충분

### 3-6. 기타

- 복수 접미사 `-들` 남용 (한국어는 복수 표시가 기본이 아니다): "사용자들은 파일들을 업로드했다" → "사용자가 파일을 올렸다"
- 인칭대명사 직역: 영어 he/she/it을 "그/그녀/그것"으로 그대로 옮김. 한국어는 이름을 반복하거나 생략한다
- 불필요한 영문 병기: "지속가능성(sustainability)" — 전문 용어 초출이 아니면 뺀다

## 4. L3 — 문장 리듬

어휘를 다 고쳐도 남는 기계 냄새의 정체가 여기 있다.

### 4-1. 3항 병렬 강박

AI는 항목이 2개나 4개여도 3개로 맞춘다. 세 번째 항목이 대개 앞의 둘을 요약하는 공허한 말이다.

> ❌ 속도, 정확도, 그리고 사용자 경험까지 개선했다
> ✅ 속도와 정확도가 올라갔다 (세 번째가 실제 없다면 쓰지 않는다)

**규칙**: 나열은 실제 항목 수대로 쓴다. 한 문서에 3항 병렬이 3회 이상 나오면 하나는 깬다.

### 4-2. 문장 길이 균일화

인간의 글은 길이가 들쭉날쭉하다. 5어절 문장 뒤에 30어절 문장이 온다. AI는 15~25어절 근처에 몰린다.

**경험 기준**: 문장 길이(어절)의 표준편차 ÷ 평균 = **변동계수 0.4 미만이면 기계적**이다. 0.5~0.7이 자연스럽다.
교정법은 문장을 짧게 자르는 게 아니라 **긴 문장과 짧은 문장을 섞는 것**이다. 전부 단문으로 만들면 균일도가 그대로라 여전히 티가 난다.

### 4-3. 종결어미 단조

- `~습니다/~합니다`만 반복, `~다`만 반복
- **기준**: 같은 종결어미가 3문장 연속이면 하나를 바꾼다
- 섞을 수 있는 것: 명사 종결, 의문, 인용(`~라고 한다`), 도치, 부사구 종결

### 4-4. 문두 접속사 사슬

`또한 / 따라서 / 하지만 / 이와 더불어 / 나아가`가 문단마다 첫 어절에 온다.

- **기준**: 문단당 문두 접속사 1개 이하
- 접속을 빼도 논리가 통하면 뺀다. 안 통하면 접속사가 아니라 문장 순서 문제다
- `또한`을 습관적으로 쓰지 말고, 병렬이면 한 문장으로 합친다

### 4-5. 대구·부정 병치 강박

- `단순한 A가 아니다. B다` 구문
- `A이자 B이며 C인` 형태
- `~하지만 동시에 ~하다`
- 수사적 질문 후 즉답 (`왜일까? 답은 단순하다.`)

한 문서에 1회면 강조, 3회 이상이면 문체 습관으로 읽힌다.

### 4-6. 쉼표 과다

AI는 영어 콤마 규칙을 한국어에 그대로 쓴다. 한국어는 어미가 이미 구를 끊어주므로 쉼표가 덜 필요하다.

> ❌ 하지만, 이 방식은, 비용이 높다는 점에서, 한계가 있다
> ✅ 하지만 이 방식은 비용이 높다

- 문두 접속사 뒤 쉼표(`따라서,`)는 대부분 불필요
- 연결어미(`~하고,` `~지만,`) 뒤 쉼표도 대부분 불필요

## 5. L4 — 문단·구성

### 5-1. 프랙탈 요약

전체에서 요약하고, 섹션에서 요약하고, 문단에서 또 요약한다. 같은 내용이 세 겹으로 반복된다.

- 도입부 예고(`~에 대해 살펴보겠습니다`) 삭제. 바로 시작한다
- 마무리 표지(`결론적으로`, `정리하면`) 삭제. 결론은 표지 없이 결론처럼 쓴다
- 각 문단 첫 문장을 주제문으로 놓는 습관: 문단 3개 이상 연속이면 하나는 사례나 수치로 시작한다

### 5-2. 양비론 마무리

> "물론 ~라는 한계가 있지만, 다른 한편으로는 ~라는 점에서 긍정적입니다"

5:5 균형을 기본값으로 배치하는 습관. 실제 근거가 6:4면 6:4로 쓴다. **판단이 필요한 자리에서 판단을 안 하면 문서 가치가 0이다.**

### 5-3. 무조건 긍정 전망

`밝은 미래가 기대된다`, `앞으로의 행보가 주목된다`, `가능성은 무궁무진하다`. 근거 없는 낙관은 삭제한다.

### 5-4. 확장 공식

`개인 → 기업 → 사회`, `과거 → 현재 → 미래`, `기술 → 산업 → 문명`으로 자동 확장하는 구조. 요청 범위를 넘는 확장은 하지 않는다.

### 5-5. 집합적 1인칭

개인 경험·특정 사안을 설명하면서 `우리는`, `우리 사회는`을 주어로 세운다. 실제 주체가 누구인지 특정한다.

### 5-6. 서식 과잉

- 짧은 글에 소제목 3단계
- 문장 중간 볼드 남발 — 한 문단에 볼드 2곳 이상이면 강조가 아니라 소음
- 이모지 불릿 (`✅ **항목**: 설명`)
- 화살표(`→`) 반복
- em dash(`—`) 남발 — 영어 문장부호 습관

**기준**: 글이 5문단 미만이면 소제목을 쓰지 않는다. 표로 정리할 게 아니면 불릿을 쓰지 않는다.

## 6. L5 — 문체 정합 (핵심)

### 6-1. 왜 문체를 지정해도 어색한가

문체는 종결어미가 아니다. **6개 축이 함께 움직이는 묶음**이다. AI는 지시를 받으면 ①만 바꾸고 ②~⑥은 기본값(문어체)으로 둔다. 그래서 "옷만 갈아입은 보고서"가 나온다.

| 축 | 격식 합쇼체 | 해요체 | 반말·구어 | 음슴체(캐주얼) | 음슴체(공문) |
|---|---|---|---|---|---|
| ① 종결어미 | ~습니다/~합니다 | ~해요/~죠 | ~해/~야/~더라 | ~음/~함/~ㅁ | ~함/~됨/~요함 |
| ② 어휘 | 한자어 허용 | 한자어 절제 | 고유어·구어 | 고유어·구어 | 한자어 허용 |
| ③ 평균 문장 길이 | 20~30어절 | 12~20어절 | 5~15어절 | 3~10어절 | 5~15어절 |
| ④ 관형절 중첩 | 2중까지 | 1중까지 | 없음 | 없음 | 1중까지 |
| ⑤ 담화표지 | 없음 | 드물게 | 잦음(근데·그냥·막) | 있음(근데·암튼) | 없음 |
| ⑥ 조사 생략 | 없음 | 드물게 | 잦음 | 매우 잦음 | 드물게 |

**교정 순서**: 지정 문체를 정한 뒤 ①→⑥ 순으로 전 문장을 훑는다. ①만 맞고 ②~⑥이 어긋나 있으면 그게 어색함의 정체다.

---

### 6-2. 음슴체

**먼저 두 종류를 구분한다. 섞으면 즉시 어색해진다.**

| | 공문서형 | 캐주얼형 |
|---|---|---|
| 용도 | 보고서 개조식, 회의록, 업무 메모 | 커뮤니티, 개인 기록, 메신저 |
| 기반 | 격식체를 압축한 것 | 반말을 압축한 것 |
| 어휘 | 확인, 조치, 판단, 검토 | 갔음, 먹음, 별로였음 |
| 예 | 재발 방지 대책 수립 필요함 | 다시 안 갈 듯. 별로였음 |

> ❌ **혼합 사고**: "어제 그 카페 갔음. 해당 매장은 접근성이 우수한 것으로 판단됨."
> ✅ 캐주얼: "어제 그 카페 갔음. 역에서 가까워서 편함."
> ✅ 공문: "○○ 매장 방문함. 역세권으로 접근성 양호함."

**AI가 자주 내는 오류**

- **어미만 갈아끼우기** — 합쇼체 문장을 그대로 두고 어미만 바꾼다
  ❌ 해당 사안에 대한 검토가 필요할 것으로 사료됨
  ✅ 이건 더 봐야 함 (캐주얼) / ○○ 건 검토 필요함 (공문)
- **문어 연결어미 잔류** — `~함에도 불구하고`, `~임에 따라`, `~하는 바`는 음슴체 리듬을 깬다. 문장을 끊는다
  ❌ 비가 왔음에도 불구하고 사람이 많았음
  ✅ 비 왔는데 사람 많았음
- **문두 접속사 잔류** — `그러나 / 또한 / 따라서`는 음슴체에 안 붙는다. `근데 / 그리고 / 그래서`로 바꾸거나 그냥 뺀다
- **존대 잔재 혼입** — `~해주셨음`, `~드림`, `~부탁드림`은 격식 음슴체 어휘다. 캐주얼에 섞지 않는다
- **조사 과잉** — 캐주얼 음슴체는 조사를 자주 생략한다. "밥을 먹었음" → "밥 먹었음"
- **문장이 길다** — 음슴체는 압축 문체다. 10어절 넘으면 두 문장으로 끊는다
- **어미 오형** — `있음`(○) / `있읍`(✕), `괜찮음`(○) / `괜찮슴`(△, 인터넷 변형체 안에서만)

**음슴체 종결 변주** (같은 어미 반복 방지): `~음/함`, `~인 듯`, `~할 듯`, `~인 편`, `~ㄹ 예정`, 명사 단독 종결

---

### 6-3. 반말·구어체

**AI가 쓰는 가짜 구어의 특징**: 문어 문장에 반말 어미를 붙이고, 실제 구어에서 안 쓰는 방식으로 구어 어미를 쓴다.

> ❌ 이건 진짜 유의미한 시사점을 던져줘
> ✅ 이거 보면 확실히 알겠더라

**어미 오용 — 실제 구어 어미에는 사용 조건이 있다**

| 어미 | 실제 조건 | AI 오용 |
|---|---|---|
| ~잖아 | 청자가 **이미 아는** 정보 | 새 정보에 붙임 → "작년에 매출이 30% 늘었잖아" (상대가 모르면 어색) |
| ~거든 | 이유·배경 제시 | 단순 서술에 붙임 → "오늘 날씨가 좋거든" (뒤에 결과가 없으면 붕 뜸) |
| ~더라 | 화자가 **직접 겪은** 과거 | 전해 들은 일·일반론에 붙임 |
| ~네 | 방금 알아차림 | 이미 알던 사실에 붙임 |
| ~ㄹ걸 | 추측·후회 | 단정에 붙임 |

**AI가 남용하는 유사 구어체**
`~인 셈이지`, `~하지 않을까 싶어`, `~라는 거야`, `~인 거지`, `~단 말이지`, `~라고 볼 수 있어`
→ 마지막 것이 특히 나쁘다. 반말 어미를 붙인 논문 문장이다. `~야` 또는 그냥 단정으로 바꾼다.

**구어의 실제 특징 — AI가 안 하는 것**

- **도치**: "나도 갔어 거기" / "괜찮더라 생각보다"
- **미완결 종결**: "그래서 좀..." / "뭐 그런 거지"
- **관형절 중첩 없음**
  ❌ 내가 어제 만난 사람이 추천한 가게가 문을 닫았어
  ✅ 어제 만난 사람이 가게 하나 추천해줬는데, 가보니까 문 닫았더라
- **담화표지**: 근데, 아니 근데, 그냥, 막, 좀, 진짜, 암튼
  단, 매 문장에 넣으면 그것도 기계적이다. 3~4문장에 1회
- **주어 생략**: 한국어 구어는 주어를 거의 안 쓴다. "나는"이 반복되면 번역투다

**반말에서 금지**: `~에 있어서`, `~를 통해`, `~인 바`, `~라 할 수 있다`, `-적/-성/-화` 연쇄, 3항 병렬

---

### 6-4. 해요체

가장 흔한 붕괴는 **합쇼체 혼입**과 **안내문 톤**이다.

- **어미 혼입**: `~해요`와 `~합니다`가 한 문단에 섞인다. 하나로 통일한다. 인용·대사만 예외
- **안내문 톤**: `~하시면 됩니다`, `~해 보세요`, `~하시기 바랍니다`가 습관적으로 나온다. 독자를 사용자로 취급하는 말투다. 설명이 필요한 자리에 명령형을 쓰지 않는다
- **`~이에요 / 예요` 받침 규칙**: 받침 있으면 `이에요`(책이에요), 없으면 `예요`(사과예요). `~이예요`는 항상 틀린 표기
- **`~죠` 남용**: `~죠`는 청자가 동의할 거라는 전제다. 새 정보나 논쟁적 주장에 붙이면 아는 척으로 읽힌다
- **문어 어휘 혼입**: 해요체는 구어 존대다. `~에 있어서`, `~를 통해`, `~의 경우`, 한자 명사 나열과 안 어울린다
  ❌ 이 방식은 비용 절감에 있어서 효과적이에요
  ✅ 이렇게 하면 돈이 덜 들어요

---

### 6-5. 격식 합쇼체

이 문체의 붕괴는 구어 혼입이 아니라 **과잉 격식**이다.

- 낡은 문어투: `~에 다름 아닙니다`, `~라 아니할 수 없습니다`, `~인 바입니다`, `~하는 바입니다`
- 과잉 겸양: `미흡하나마`, `감히 말씀드리자면`, `외람되오나`
- 사료됨·판단됨 계열: `~로 사료됩니다`, `~로 판단됩니다` → `~라고 봅니다`
- 격식 ≠ 한자어 밀도. 격식체에서도 서술어는 동사로 푼다

---

### 6-6. 문체 통일의 예외 구간

문체를 통일하되 다음은 예외다.

- 인용문·대사: 원 화자의 문체를 유지한다
- 표 안의 항목: 명사 종결로 통일한다(본문이 해요체여도)
- 제목·소제목: 명사구로 통일한다
- 목록: 목록 안에서는 어미를 통일한다. 본문과 달라도 된다

## 7. 치환 사전 + 오탐 가이드

**중요: 아래 표의 우측 열은 금지어가 아니다.** 각 항목에는 오히려 그 표현이 정확한 맥락이 있다. 기계적으로 치환하면 문장이 뭉개진다.

| 의도 | 자연스러운 표현 | AI 전형 | 오히려 맞는 맥락 |
|---|---|---|---|
| 기준·중심 잡기 | 기준을 정하다, 중심을 잡다 | 축을 세우다, 기준을 가르다 | 좌표계·역학 등 실제 물리 구조를 말할 때 |
| 강조·마무리 | 강조하다, 힘을 싣다 | 방점을 찍다 | 문서 안에서 딱 1회, 진짜 결정적 지점에 |
| 상태의 유사성 | 비슷하다, 방향이 같다 | 결을 같이하다, 궤를 같이하다 | 궤도·궤적을 다루는 이공계 문맥 |
| 시작·계기 | 계기가 되다, 시작점이 되다 | 단초를 제공하다, 마중물이 되다 | 정책·재정 문맥의 '마중물'은 관용 정착어 |
| 차이 줄이기 | 격차를 줄이다, 차이를 좁히다 | 간극을 메우다 | 세대·인식 '간극'은 굳은 표현 |
| 심층 분석 | 자세히 보다, 뜯어보다 | 깊이 파고들다, 입체적으로 조명하다 | 실제 다층 분석을 수행했을 때 |
| 의미 부여 | 중요한 의미가 있다 | 시사하는 바가 크다 | 시사점을 곧바로 특정해서 쓸 때만 |
| 대비 서술 | ~뿐 아니라 ~도 | 단순히 ~에 그치지 않고 | 통념을 실제로 뒤집을 때 1회 |
| 범위 확대 | 범위를 넓히다 | 외연을 확장하다, 지평을 넓히다 | 논리학·집합 개념의 '외연' |
| 장단점 공존 | 장단점이 같이 있다 | 양날의 검 | 위험이 실제로 대칭일 때 |
| 절충 | 적정선을 찾다 | 균형점을 찾다 | 수치상 최적점이 실재할 때 |
| 원인 | ~ 때문에, ~라서 | ~로 인해, ~에 기인하여 | 공문서 격식이 필요할 때 |
| 방법 | ~해서, ~로 | ~를 통해 | 실제 매개·경유를 뜻할 때 |
| 검토 필요 | 더 봐야 한다 | 다각도로 조명해 볼 필요가 있다 | 무엇을 더 봐야 하는지 특정했을 때 |
| 기여 | ~에 도움이 됐다 | ~에 기여했다, 역할을 톡톡히 해냈다 | 기여도를 수치로 밝힐 때 |
| 변화 | 바뀌었다 | 패러다임이 전환됐다 | 실제로 전제가 바뀐 경우 |
| 다양함 | 세 가지, 몇 가지 (수를 밝힘) | 다양한, 여러 | 수를 셀 수 없을 때 |
| 중요함 | 중요하다 (이유와 함께) | 핵심적이다, 필수적이다 | 다른 것과의 우선순위를 밝혔을 때 |

## 8. 과교정 경고

금지어 목록을 기계적으로 적용하면 **새로운 종류의 AI 티**가 생긴다. 실제로 자주 발생하는 부작용이다.

| 과교정 | 결과 | 원칙 |
|---|---|---|
| 문장을 전부 짧게 자름 | 단문 균일 → 리듬 변동계수가 다시 0에 가까워짐. 여전히 기계적 | 길이를 **섞는다**. 짧게 만드는 게 목적이 아니다 |
| 한자어를 전부 고유어로 | 유아적이고 정보 밀도가 떨어짐 | 한자어 자체가 문제가 아니라 **명사 연쇄**가 문제다 |
| hedging 전면 제거 | 근거 없는 단정 → 신뢰도 하락 | 불확실한 건 불확실하다고 쓴다. 문제는 **모든 문장**에 붙이는 것 |
| 접속사 전면 제거 | 논리 비약 | 문두 접속사를 줄이되, 인과 관계는 문장 안에서 밝힌다 |
| 표·불릿 전면 금지 | 비교 정보가 산문에 묻힘 | 비교·조건은 표가 낫다. 문제는 **서사에 불릿을 쓰는 것** |
| 담화표지 억지 삽입 | "근데 진짜 막 그냥"이 매 문장에 → 더 부자연스러움 | 3~4문장에 1회 |
| 구어 어미 총동원 | `~잖아 ~거든 ~더라`가 한 문단에 다 나옴 | 조건에 맞는 것만 쓴다(§6-3) |

**공통 원칙: 이건 빈도의 문제이지 존재의 문제가 아니다.**
`방점을 찍다`가 한 번 나오면 문제없다. 세 번 나오면 문체 습관이고, 그게 AI 지문이다.

## 9. 자가 점검 절차

작성 후 4단계로 훑는다. 1·2단계는 기계로, 3·4단계는 읽으면서 한다.

**1단계 — 어휘 검색 (L1, L2)**
아래 정규식으로 걸러낸다.

```
(궤를|결을 (맞|같)|축을 (세|형성)|방점|무게추|외연을|지평을|간극|파고들|양날의|태피스트리|시사하는 바|단초를|마중물|톡톡히|귀추|다각도로 조명)
(되어지|보여지|불려지|쓰여지|잊혀지)
(에 있어서|에 다름 아니|를 통해|에 대한|로 인해|것으로 사료|것으로 판단)
(다양한|혁신적|획기적|효과적으로|성공적으로|궁극적으로|유기적으로)
```

주의: 이 문서 자체를 검색하면 전부 걸린다. 예시로 인용한 표현이기 때문이다. 검색 대상은 본문이지 규칙집이 아니다.

**2단계 — 리듬 측정 (L3)**
번들 스크립트(`scripts/check_style.py`)로 4개 지표를 본다.

| 지표 | 경고 기준 | 왜 이 값인가 |
|---|---|---|
| 문장 길이 변동계수 (표준편차÷평균) | 0.40 미만 | 사람 글은 0.5~0.7. 0.4 아래는 길이가 한 곳에 몰린 것 |
| 최빈 종결형 비율 (끝 3음절 기준) | 60% 초과 | 2음절로 재면 `~니다`가 전부 한 덩어리로 잡혀 격식 문서가 오탐된다. 3음절이라야 `습니다/입니다/봅니다`가 구분된다 |
| 문두 접속사 비율 | 문장의 20% 초과 | 5문장에 1개까지가 자연스럽다 |
| 문장당 쉼표 | 평균 1.0개 초과 | 한국어는 어미가 이미 구를 끊는다 |

실측 예 (`examples/` 표본 기준):

| | AI가 쓴 5문장 | 사람이 쓴 6문장(격식) |
|---|---|---|
| 길이 변동계수 | 0.20 ▲ | 0.39 |
| 최빈 종결형 | `습니다` 60% ▲ | `습니다` 57% |
| 문두 접속사 | 40% ▲ | 0% |

**3단계 — 문체 정합 (L5)**
§6-1 표를 놓고 6개 축을 대조한다. 특히 ②어휘와 ④통사가 ①어미를 따라왔는지 본다.

**4단계 — 발화 가능성 검사**
문장을 하나씩 골라, **그 문체가 쓰이는 실제 상황에서 입으로 말할 수 있는지** 본다.
음슴체는 메모로 적을 수 있는지, 반말은 친구에게 말할 수 있는지, 해요체는 소리 내어 말할 수 있는지 본다.
말이 안 나오면 그 문장이 문제다. 이 검사가 앞의 셋을 다 통과한 문장도 걸러낸다.

## 10. 우선순위

시간이 없을 때 이 순서로 본다.

1. **L5 문체 정합** — 어색함 체감의 대부분
2. **L3 리듬** — 어휘를 다 고쳐도 남는 기계 냄새
3. **L2 문법** — 이중 피동, `-적/-성/-화` 연쇄, 무생물 주어
4. **L1 어휘** — 검색 치환으로 가장 빨리 끝남
5. **L4 구성** — 문서 종류에 따라 허용치가 다름

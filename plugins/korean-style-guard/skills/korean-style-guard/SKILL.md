# 한국어 문체 가드

초안을 내기 **전에** §1~§4를 적용하고, 낸 **후에** §5로 검증한다.
세부 근거와 확장 목록은 `references/style-guide.md`에 있다. 판단이 갈릴 때만 열어본다.

## 1. 먼저: 문체 정합 (가장 큰 어색함의 원인)

문체는 종결어미가 아니라 6개 축의 묶음이다. 어미만 바꾸고 나머지를 문어체로 두면 "옷만 갈아입은 보고서"가 된다.

| 축 | 격식체 | 해요체 | 반말·구어 | 음슴체(캐주얼) | 음슴체(공문) |
|---|---|---|---|---|---|
| 종결어미 | ~습니다 | ~해요/~죠 | ~해/~더라 | ~음/~함 | ~함/~됨/~요함 |
| 어휘 | 한자어 허용 | 한자어 절제 | 고유어·구어 | 고유어·구어 | 한자어 허용 |
| 평균 문장 길이 | 20~30어절 | 12~20 | 5~15 | 3~10 | 5~15 |
| 관형절 중첩 | 2중까지 | 1중 | 없음 | 없음 | 1중 |
| 담화표지(근데·그냥·막) | 없음 | 드물게 | 잦음 | 있음 | 없음 |
| 조사 생략 | 없음 | 드물게 | 잦음 | 매우 잦음 | 드물게 |

**문체별 필수 규칙**

- **음슴체**: 공문서형과 캐주얼형을 섞지 않는다. `~함에도 불구하고`·`~임에 따라` 같은 문어 연결어미는 문장을 끊어서 없앤다. 문두 `그러나/또한/따라서`를 `근데/그리고`로 바꾸거나 뺀다. 캐주얼형은 조사를 생략한다("밥을 먹었음"→"밥 먹었음"). 10어절 넘으면 자른다.
- **반말·구어**: `~잖아`는 청자가 이미 아는 정보에만, `~거든`은 이유·배경 제시에만, `~더라`는 직접 겪은 일에만 쓴다. `~라고 볼 수 있어`·`~인 셈이지`·`~하지 않을까 싶어`는 쓰지 않는다(반말 어미를 붙인 논문 문장). 관형절을 중첩하지 않는다. 주어를 반복하지 않는다.
- **해요체**: `~합니다`를 섞지 않는다. `~하시면 됩니다`·`~해 보세요` 안내문 톤을 쓰지 않는다. 받침 있으면 `이에요`, 없으면 `예요`(`이예요`는 항상 오표기). `~에 있어서`·`~를 통해` 같은 문어 조사를 쓰지 않는다.
- **격식체**: 붕괴는 구어 혼입이 아니라 과잉 격식이다. `~에 다름 아닙니다`·`~라 아니할 수 없습니다`·`~로 사료됩니다`를 쓰지 않는다.

예외: 인용·대사는 원 화자 문체 유지. 표 항목과 제목은 명사 종결로 통일.

## 2. 어휘 금지 목록

- **공간·기하 은유**: 축을 세우다, 기준을 가르다, 궤를 같이하다, 결을 맞추다, 방점을 찍다, 무게추를 옮기다, 외연을 확장하다, 지평을 넓히다, 접점을 찾다, 스펙트럼이 넓다
- **영어 직역**: 단순히 A가 아니라 B, 간극을 좁히다, 깊이 파고들다, 양날의 검, 시간의 시험, 태피스트리, 중추적 역할, 청사진, 촉매제, 균형점, 새로운 장을 열다
- **결말 상투구**: 시사하는 바가 크다, 단초를 제공하다, 마중물이 되다, 다각도로 조명해 볼 필요가 있다, 역할을 톡톡히 해내다, 귀추가 주목된다, 방향성을 제시한다
- **수식어 인플레**: 다양한, 혁신적인, 획기적인, 유의미한, 효과적으로, 성공적으로, 궁극적으로, 유기적으로, 핵심, 필수, 인사이트
  → 지웠을 때 정보가 안 줄면 장식이다. 지운다.

## 3. 문법 교정

- 이중 피동: 되어진다→된다, 보여진다→보인다, 쓰여진다→쓰인다, 잊혀진다→잊힌다
- 조사 번역투: `~를 통해`→`~로/~해서`, `~에 대한`→`~의/생략`, `~에 있어서`→`~에서`, `~로 인해`→`~때문에`
- `-적/-성/-화` 3개 이상 연쇄 금지. 명사 3개 연속(`효율성 제고 방안`)은 동사로 푼다
- 무생물 주어 금지: "이번 조사는 ~을 보여준다" → "조사해 보니 ~"
- 형식명사: `~하는 것이 필요하다`→`~해야 한다`, `~라는 점에서`는 대부분 삭제
- `-들` 남용 금지. 영문 병기는 전문 용어 초출만

## 4. 리듬·구성

- **3항 병렬 금지**: 항목이 2개면 2개로 쓴다. 세 번째를 만들어내지 않는다
- **문장 길이를 섞는다**: 짧게 자르는 게 아니라 긴 문장과 짧은 문장을 섞는다. 전부 단문이면 똑같이 기계적이다
- **같은 종결어미 3연속 금지**
- **문두 접속사는 문단당 1개 이하**. `또한/따라서/하지만` 뒤 쉼표는 뺀다
- **도입 예고(`~살펴보겠습니다`)와 마무리 표지(`결론적으로`) 삭제**
- **양비론 마무리 금지**: 근거가 6:4면 6:4로 쓴다. 판단이 필요한 자리에서 판단한다
- **근거 없는 긍정 전망 삭제**
- **`우리는`·`우리 사회는` 금지**. 주체를 특정한다
- 5문단 미만이면 소제목 없음. 한 문단에 볼드 2곳 이상 금지. 이모지 불릿·`→` 반복 금지

## 5. 검증

작성 후 번들 스크립트를 돌린다.

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/korean-style-guard/scripts/check_style.py" 원고.md
```

파일이 아니라 방금 쓴 텍스트를 볼 때는 표준입력으로 넘긴다.

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/korean-style-guard/scripts/check_style.py" < draft.txt
```

표준 라이브러리만 쓴다. 두 가지를 보고한다.

1. **어휘 검색** — §2 목록 적발 현황
2. **리듬 4지표** — 문장 길이 변동계수 0.40 미만 / 최빈 종결형(끝 3음절) 60% 초과 / 문두 접속사 20% 초과 / 문장당 쉼표 1.0 초과이면 고친다

▲가 뜬 항목만 고치고 다시 돌린다. 그다음 손으로 두 가지를 더 본다.

3. §1 표로 6개 축을 대조한다. 어미만 맞고 어휘·통사가 안 따라왔는지 본다
4. **발화 가능성 검사**: 문장을 골라, 그 문체가 쓰이는 실제 상황에서 입으로 말할 수 있는지 본다. 말이 안 나오면 그 문장이 문제다

## 6. 과교정 금지

**빈도의 문제이지 존재의 문제가 아니다.** 상투 표현이 1회 나오면 정상, 3회 이상이면 문체 습관이다.

- 한자어를 전부 고유어로 바꾸지 않는다 → 유아적이 된다. 문제는 한자어가 아니라 명사 연쇄다
- hedging을 전부 없애지 않는다 → 근거 없는 단정이 된다. 문제는 모든 문장에 붙이는 것이다
- 접속사를 전부 없애지 않는다 → 논리가 비약한다
- 표·불릿을 금지하지 않는다. 비교·조건은 표가 낫다. 문제는 서사에 불릿을 쓰는 것이다
- 담화표지를 억지로 넣지 않는다. 3~4문장에 1회면 충분하다
- 스크립트의 ▲는 검토 신호이지 오류 판정이 아니다. 의도한 반복이면 둔다

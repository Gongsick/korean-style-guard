---
description: 한국어 원고의 AI 문체를 점검한다 (파일 경로 또는 붙여넣은 글)
argument-hint: [파일 경로] [--style 문체]
---

`$ARGUMENTS`를 대상으로 한국어 문체를 점검한다. 인자가 비어 있으면 직전 대화에서 작성한 한국어 원고를 대상으로 삼고, 그것도 없으면 점검할 글을 붙여넣어 달라고 요청한다.

1. `korean-style-guard` 스킬을 읽는다.
2. 사용자가 문체를 지정했거나 원고의 문체가 분명하면 `--style`을 붙인다. 문체 이름은 `음슴체-캐주얼`, `음슴체-공문`, `반말-구어`, `해요체`, `격식-합쇼체` 이며 `음슴체`·`반말`·`격식체` 같은 별칭도 받는다.

   ```bash
   python3 "${CLAUDE_PLUGIN_ROOT}/skills/korean-style-guard/scripts/check_style.py" --style <문체> <대상>
   ```

   붙여넣은 글이면 임시 파일로 저장한 뒤 같은 명령을 돌린다.
3. 결과를 다음 형식으로 보고한다.
   - **▲ 걸린 항목**: 지표명 / 측정값 / 해당 문장
   - **수정 제안**: 문장별 before → after
   - **문체 정합**: 3단계 결과에서 종결어미·금지 표현·구어 표지를 짚는다
4. 스킬 §6에 따라 과교정을 피한다. 밀도 기준 이하 등장은 정상으로 처리하고, 의도한 반복은 그대로 둔다. 담화표지를 억지로 채워 넣지 않는다.
5. 사용자가 수정을 원하면 고친 원고를 내고 스크립트를 다시 돌려 지표 변화를 보여준다.
